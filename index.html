What the converter does (steps, in order)
  • old script: * → ñ; sh'sh/s'sh → cc; sh → c; R → ç inside a word only (a word-initial R is a capital r); no' → no + space; hyphens → space; '' → "; a detached ot/ottu gets its accent (ót/ottú). Protected names keep their sh / R.
  • spelling corrections: whole-word corrections agreed with the linguists (né, cis) and the consistent corrections from the Gamayun kit (babute → baabute, aañi → Añí).
  • ót / ottú separated: after a consonant, ót / ottú is a separate word (ghorot → ghor ót, Jacobottu → Jacob ottú). Kept joined: whole dictionary words (modot, izzot), vowel stems (hitattu), -ccot.
  • Correct Spellings (xlsx): the “Correct Spellings” tab of the standardization sheet.
  • ending after name: after a protected name, subject e/ye, object re/ore, possessive or, ót and ottú are separate; r/ar, ttu, olla, lla are joined.
  • apostrophe removed; pronoun stem: aañr → añár, tuañ → tuáñ, other old aañ → añ.
  • marker table: forms listed in the possessive / at-on-in / from marker tables are used as written. X ót is re-joined when Xot is a whole word, and ottú is joined after a c stem or when the table lists the joined form.
  • spelling map (dictionary): the dictionary accent map in kb/spellings.tsv: an unaccented word becomes the accented form the dictionary uses (hite → híte, maze → mazé). Skipped when the unaccented spelling is itself a dictionary word, and for protected names and English words.
  • Not handled: numbers (spell them out), past tense no/nóo, Maungdaw variants, translation fixes. The standard is still evolving, so always review the output.
